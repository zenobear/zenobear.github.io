Connect your Supabase database

This POS uses Supabase (a hosted Postgres database) as its live backend, so every device — phone, tablet, or PC — reads and writes the same real-time inventory and sales, with proper safeguards against overselling. Set it up once:

  1. Create a free project at supabase.com.
  2. Open SQL Editor → New query, paste the schema below, click Run.
  3. Go to Project Settings → API.
  4. Copy the Project URL and the anon public key.
  5. Paste both below and connect.

Supabase connection
All products, stock, and sales live in this database — every device using these same credentials shares the same data, live, via Realtime.
Database schema (Supabase SQL)

This is the full schema — tables, Row Level Security, and the functions that run every sale, stock-in, return, and exchange as a single atomic database transaction so two devices can never both sell the last unit.

Data & security notes
Your data lives in Supabase, not on this device — use Supabase's dashboard (Database → Backups) for backups.

Because there's no login system, the "anon" key embedded in this app can read every table. It can only write through the guarded functions above (never directly to a table), so it can't corrupt stock or skip the discount/oversell checks — but treat this like any tool with no password: don't hand the URL out publicly if the sales data should stay private.
